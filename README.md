# 合理用药：给宿舍药箱上堂课

苏州大学选修课双人课堂展示。全套材料围绕“合理用药”分为四部分：基本原则、宿舍常见误区、安全用药方法、情境选择挑战。主讲约 35 分钟，包含举手互动。

## 直接使用

| 文件 | 用途 |
| --- | --- |
| [可编辑 PPT](交付文件/合理用药_双人35分钟.pptx) | 27 页主讲，另有 3 页隐藏的文献、2 页隐藏的图片来源；逐页讲稿已写入备注 |
| [PPT 预览 PDF](交付文件/合理用药_双人35分钟.pdf) | 固定版式预览；默认只含 27 页主讲内容 |

| [大纲与逐页设计说明](交付文件/合理用药_大纲与逐页设计说明.docx) | 四部分大纲、每页短文案、视觉建议、数据口径与参考资料 |

## 设计与资料

- 配色：蓝 `#153E75`、红 `#E3464F`、白 `#FFFFFF`；图示增加青绿、紫色、橙黄点缀；照片保留自然色。
- 17幅独立动漫分镜、6张实拍照片均只出现一次。第5页为宿舍三格，第7页为全新核药时间线，第13页为过敏用药与课堂犯困对照，第16页为聚餐三格；四道题与综合案例均用独立画面。第4页文字卡保留柔和底色，第6页成分图保留精简配色。对白、机制与图表可编辑。
- 第7页为信息核对案例，时间线不代表推荐给药间隔。第8、25页为多选，答案A＋C、A＋B；第3、15页为单选。第15页先投票，第16页聚餐案例再揭晓C。
- 第11页用100格展示美国门诊抗生素处方至少28%被估计为不必要；五个急诊图标突出药物相关急诊中约1/5涉及抗生素反应。统计范围与来源在备注和附页，不把急诊比例解释为服药者个人风险或全部滥用后果。
- 上轮第5页移至案例三（现第13页），原第14页重复犯困内容删除，主讲现为27页。总结路线仍在第2页，计划35分钟；完整新旧页码对照见核验报告。
- `source/visuals.py` 保存漫画排版与可编辑图示；`source/assets/anime/` 保存动漫原图和素材说明；`source/qa_report.json` 记录本次生成核验。

`source/` 保存生成 PPT 与 Word 的 Python 脚本，`source/assets/photos/` 保存照片素材及许可记录。如需重新生成，安装 `source/requirements.txt` 后在该目录运行 `python build.py`；脚本会把文件输出到 `source/交付文件/`。正常课堂使用无需运行脚本。

- 情境漫画取消“情境／对话／悬念”等阶段标签和重复小标题，以人物互动及对白推进故事；实际时间、题型和医学机制标注保留。
- 主讲页取消“虚构情境”、微型来源行及统计方法说明，保留短结论、必要分母与医学机制标注；依据完整保存在备注、附页和配套资料。
