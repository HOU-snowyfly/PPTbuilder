# 合理用药：给宿舍药箱上堂课

苏州大学选修课双人课堂展示。全套材料围绕“合理用药”分为四部分：基本原则、宿舍常见误区、安全用药方法、情境选择挑战。主讲约 35 分钟，包含举手互动。

## 直接使用

| 文件 | 用途 |
| --- | --- |
| [可编辑 PPT](交付文件/合理用药_双人35分钟.pptx) | 30 页主讲，另有 3 页隐藏的参考资料；逐页讲稿已写入备注 |
| [PPT 预览 PDF](交付文件/合理用药_双人35分钟.pdf) | 固定版式预览；默认只含 30 页主讲内容 |
| [双人逐页讲稿](交付文件/合理用药_双人逐页讲稿.docx) | 主讲分工、交接台词、互动主持词和累计时间 |
| [大纲与逐页设计说明](交付文件/合理用药_大纲与逐页设计说明.docx) | 四部分大纲、每页短文案、视觉建议、数据口径与参考资料 |
| [图表原始数据与口径](交付文件/图表原始数据与口径.csv) | 第 8、13 页图表的数据及解释边界 |
| [来源链接与使用说明](交付文件/来源链接与使用说明.txt) | 权威来源链接、字体及放映提示 |
| [全套 ZIP](合理用药_全套展示资料.zip) | 上述资料的一次性下载版本 |

Word 材料也提供 PDF 预览，均在 `交付文件/` 目录。使用前把封面的“同学甲 / 同学乙”替换为姓名，并在实际展示电脑上完整计时排练一次。

## 设计与资料

- 配色：蓝 `#153E75`、红 `#E3464F`、白 `#FFFFFF`。
- 宿舍人物与情节为虚构教学情境。插画和图表在 PPT 中可编辑。
- 第 8 页引用的 23.8% 与 45.6% 来自美国成人模拟用药研究，属于潜在超量风险，不能相加，也不是实际中毒率。
- 第 13 页引用 2019 年全球细菌耐药负担的两个不同统计口径，不能相加。所有来源见附页和配套说明。

`source/` 保存生成 PPT 与 Word 的 Python 脚本。如需重新生成，安装 `source/requirements.txt` 后在该目录运行 `python build.py`；脚本会把文件输出到 `source/交付文件/`。正常课堂使用无需运行脚本。
