# 合理用药课堂PPT

苏州大学选修课双人展示，面向具有高中生物基础的非医学专业大一学生。27页主讲，计划35分钟，包含互动；另有6页隐藏的资料与素材附页。

## 交付文件

仅保留两份成品：

- [可编辑PPT](交付文件/合理用药_双人35分钟.pptx)：完整页面、可编辑文字与逐页备注。
- [双人逐页讲稿](交付文件/合理用药_双人逐页讲稿.docx)：主讲分工、人物情境、互动答案、过渡与累计时间。

使用前替换封面的同学甲／同学乙姓名，并进行实际计时排练。PDF、ZIP、预览图、设计说明和其他交付附件已移除；验证用文件只存于本地work/。

## 当前制作方向

- 简洁专业的杂志排版：以字号、列宽、浅底色和留白建立层次。文字页12、17、18、21、22、26、27，以及题目页3、8、15、25，均无人物或装饰插图。
- 七个情景页全部保留。5、13、16、24为重点故事，7、19、20为轻量场景；采用成熟出版物编辑插画。同一故事角色连续，不同案例更换主角、服装和场景。
- 四个主要人物为小周、晓岚、阿明与小林。14幅编辑场景各出现一次；10、14页另用4幅独立科学插图。封面与收尾采用主题排版。
- 第6页成分图、第11页数据图与第14页机制图的原有展示保持。数据口径与依据保存在备注和隐藏附页。
- 第3、15页单选，第8、25页多选；投票后再揭晓。选项等权呈现，不以人物图或特殊颜色暗示答案。

## 规则与源码

[PPT_SKILL](PPT_SKILL/)包含逻辑、文本内容、文本显示形式、图片及小问题补丁；[SKILL.md](SKILL.md)保存核心摘要与执行规则。

源码：source/content.py保存文案与放映顺序，source/editorial_visuals.py保存杂志版式与场景分配，source/medical_visuals.py保存科学图布局，source/visuals.py保存成分、数据等可编辑图示，source/build.py仅生成PPTX和讲稿DOCX。当前素材位于source/assets/editorial/与source/assets/medical/；旧素材保留为历史制作资料。

安装source/requirements.txt后运行python source/build.py，生成文件位于source/交付文件/。source/qa_report.json记录实际PDF文字、图片使用、页码、选项、边界及时间节点的核验。正常展示无需运行代码。
