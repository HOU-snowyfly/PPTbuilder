# 合理用药：给宿舍药箱上堂课

苏州大学选修课双人课堂展示。全套材料围绕“合理用药”分为四部分：基本原则、宿舍常见误区、安全用药方法、情境选择挑战。主讲约 35 分钟，包含举手互动。

## 设计与资料

- 配色：蓝 `#153E75`、红 `#E3464F`、白 `#FFFFFF`；图示使用少量协调强调色；正文采用浅底色卡片、气泡与行动带。
- 封面重做：白底深蓝“合理用药”74pt大标题与全新动漫核药画面，呼应整稿。第17—27页按PPT_SKILL整改：查说明书、核使用要求、问药师、识别求助信号、保留记录、综合练习。全稿26幅动漫画面各出现一次，不使用图库照片；对白、机制与图表可编辑。
- 第7页为信息核对案例，时间线不代表推荐给药间隔。第8、25页为多选，答案A＋C、A＋B；第3、15页为单选。第15页先投票，第16页聚餐案例再揭晓C。
- 第11页用100格展示美国门诊抗生素处方至少28%被估计为不必要；五个急诊图标突出药物相关急诊中约1/5涉及抗生素反应。统计范围与来源在备注和附页，不把急诊比例解释为服药者个人风险或全部滥用后果。
- 上轮第5页移至案例三（现第13页），原第14页重复犯困内容删除，主讲现为27页。总结路线仍在第2页，计划35分钟；稳定内容编号与页码对应见核验报告。
- `source/visuals.py` 保存前半段漫画与可编辑图示，`source/late_visuals.py` 保存封面及第17—27页布局；`source/assets/anime/` 保存动漫原图和素材说明；`source/qa_report.json` 记录本次生成核验。

`source/` 保存生成 PPT 与 Word 的 Python 脚本，`source/assets/anime/` 保存当前动漫素材；`source/assets/photos/` 为未使用的旧图库素材。如需重新生成，安装 `source/requirements.txt` 后在该目录运行 `python build.py`；脚本会把文件输出到 `source/交付文件/`。正常课堂使用无需运行脚本。

- 情境漫画取消“情境／对话／悬念”等阶段标签和重复小标题，以人物互动及对白推进故事；实际时间、题型和医学机制标注保留。
- 主讲页取消“虚构情境”、微型来源行及统计方法说明，保留短结论、必要分母与医学机制标注；依据完整保存在备注、附页和配套资料。

- 第24页先展示三格情境，第25页等权多选，第26页揭晓A＋B；第27页呼应封面。整改页的逐页位置理由写入设计说明，第2—16页实际PDF画面与前版逐页比对一致。
