# 合理用药：给宿舍药箱上堂课

苏州大学选修课双人课堂展示。全套材料围绕“合理用药”分为四部分：基本原则、宿舍常见误区、安全用药方法、情境选择挑战。主讲约 35 分钟，包含举手互动。

## 直接使用

| 文件 | 用途 |
| --- | --- |
| [可编辑 PPT](交付文件/合理用药_双人35分钟.pptx) | 30 页主讲，另有 3 页隐藏的文献、2 页隐藏的图片来源；逐页讲稿已写入备注 |
| [PPT 预览 PDF](交付文件/合理用药_双人35分钟.pdf) | 固定版式预览；默认只含 30 页主讲内容 |
| [双人逐页讲稿](交付文件/合理用药_双人逐页讲稿.docx) | 主讲分工、交接台词、互动主持词和累计时间 |
| [大纲与逐页设计说明](交付文件/合理用药_大纲与逐页设计说明.docx) | 四部分大纲、每页短文案、视觉建议、数据口径与参考资料 |
| [图表原始数据与口径](交付文件/图表原始数据与口径.csv) | 第 13 页统计图的数据及解释边界 |
| [来源链接与使用说明](交付文件/来源链接与使用说明.txt) | 权威来源链接、字体及放映提示 |
| [真实照片来源](交付文件/真实照片来源.csv) | 9 张实拍图库照片的原图、摄影者、许可和使用页码 |
| [全套 ZIP](合理用药_全套展示资料.zip) | 上述资料的一次性下载版本 |

Word 材料也提供 PDF 预览，均在 `交付文件/` 目录。使用前把封面的“同学甲 / 同学乙”替换为姓名，并在实际展示电脑上完整计时排练一次。

## 设计与资料

- 配色：蓝 `#153E75`、红 `#E3464F`、白 `#FFFFFF`；图示增加青绿、紫色、橙黄点缀；照片保留自然色。
- 12 页保留真实照片；第 6、15 页采用小苏与室友的三格彩色漫画。成分、细菌与病毒、组胺机制图均为可编辑形状。照片只作场景示意；人物与情节为虚构教学情境。
- 第 8 页改为已服药后仍不舒服的信息核对案例；时间线不代表推荐给药间隔。第 9、28 页为多选，答案分别为 A＋C、A＋B；第 3、19 页保留单选。
- 第 13 页解释相关死亡与归因死亡的不同假设，使用共用刻度和95%不确定性区间，不能相加。所有来源见附页和配套说明。
- 路线总结已移至第 2 页；原第 2、3、4 页依次变为第 3、4、5 页，其他主讲页码不变。
- `source/visuals.py` 保存可编辑漫画与图示；`source/qa_report.json` 记录本次生成核验。

`source/` 保存生成 PPT 与 Word 的 Python 脚本，`source/assets/photos/` 保存照片素材及许可记录。如需重新生成，安装 `source/requirements.txt` 后在该目录运行 `python build.py`；脚本会把文件输出到 `source/交付文件/`。正常课堂使用无需运行脚本。
