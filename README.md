# 合理用药课堂PPT

苏州大学选修课双人展示，面向具有高中生物基础的非医学专业大一学生。27页主讲，计划35分钟，包含互动；另有6页隐藏的资料与素材附页。

## 当前制作方向

- 精致专业的编辑排版：统一字体、配色和间距，通过暖白材质、局部深色渐变、图文组合与分层字重建立层次。文字页12、17、18、21、22、26、27，以及题目页3、8、15、25，均无人物或装饰插图。
- 七个情景页全部保留。5、13、16、24为重点故事，7、19、20为轻量场景；采用成熟出版物编辑插画。同一故事角色连续，不同案例更换主角、服装和场景。
- 四个主要人物为小周、晓岚、阿明与小林。14幅编辑场景各出现一次；10、14页另用4幅独立科学插图。封面与收尾采用主题排版。
- 第6页成分对应关系、第11页数值与分母、第14页机制结构和标签位置保留；新版优化视觉呈现。数据口径与依据保存在备注和隐藏附页。
- 第3、15页单选，第8、25页多选；投票后再揭晓。选项等权呈现，不以人物图或特殊颜色暗示答案。

## 规则与源码

[PPT_SKILL](PPT_SKILL/)包含[全局样式](PPT_SKILL/全局样式)、逻辑、文本内容、文本显示形式、[配图](PPT_SKILL/配图)及小问题补丁。“全局样式”统筹整套视觉规则、灵活版式与页间连贯，采用“自动制定方案→少量真实样页确认→完成整套”的流程。原“图片”要求已合并至“配图”，其中第8节提供数据图的选型、制作提示词与核验要求。[SKILL.md](SKILL.md)保存核心摘要与执行规则。

源码：source/content.py保存文案与放映顺序，source/editorial_visuals.py保存原版杂志布局与场景分配，source/medical_visuals.py保存科学图布局，source/visuals.py保存成分、数据等可编辑图示。source/build.py保留原版生成方式；source/build_refined_deck.py生成独立精致编辑版，复用已确认样页组件并保持原版不变。实际渲染后，source/qa_refined_deck.py检查保存后的页面、图片、讲稿与PDF文字；核验结果见source/refined_qa_report.json。

源素材位于source/assets/editorial/、source/assets/medical/与source/assets/editorial_surface/。临时样页在全套定稿后清理，生成源码保留供复现；旧素材留作历史制作资料。

安装source/requirements.txt后运行python source/build.py，生成文件位于source/交付文件/。source/qa_report.json记录实际PDF文字、图片使用、页码、选项、边界及时间节点的核验。正常展示无需运行代码。
